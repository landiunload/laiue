## О проекте

`laiue` — встраиваемый модульный движок на C17 для любых приложений;
воксельные миры — лишь один из его модулей. Windows
собирает полный графический набор без CRT; Linux, macOS и внешние
(mobile/консольные) профили собирают переносимое headless-ядро на x86_64 и
ARM64. Бэкенд рендера выбирается отдельно от платформы: `D3D12` только на
Windows, а переносимый `VULKAN` без оконного хендла рисует кадр offscreen,
а с окном выводит его через swapchain Win32 или Xlib.
При `AUTO` на Windows с найденным Vulkan SDK линкуются оба бэкенда,
`RendererCreate` по умолчанию даёт D3D12, а конкретный выбирает
`RendererCreateWithBackend`. На Linux графический набор Vulkan добавляет
окно и ввод поверх X11, если он найден; на macOS окна и ввода движка нет.
Наличие core-сборки не означает наличие окна или рендера. Приложение
линкует только `laiue::bootstrap` и загружает модули по имени
(`LaiueModuleHostLoadNamedProfileV1`), поэтому отсутствие любого модуля
отключает лишь его технологию.
Мир по умолчанию пуст; внешний базовый слой подключается через
`WorldBaseProvider`,
а бесконечные абсолютные координаты сохраняются через rebasing. Нативные
моды подключаются через отдельный versioned service ABI; серверной,
сетевой, игровой и процедурно-генерирующей политики в движке нет.

Канонические правила находятся в [CONTRIBUTING.md](CONTRIBUTING.md), команды
и входная документация — в [README.md](README.md). Текущий прикладной проект —
[landiunload/simulation-of-sins](https://github.com/landiunload/simulation-of-sins);
прежний сохранён в [landiunload/laiue-game](https://github.com/landiunload/laiue-game).
