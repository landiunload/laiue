# Форматы содержимого

| Назначение | Одиночный формат | Пак | Runtime-каталог |
|---|---|---|---|
| шейдеры | `.ls` | `.lsp` | `shaders/` |
| текстуры | `.lt` | `.ltp` | `textures/` |
| звуки | `.la` | `.lap` | `sounds/` |

`.ls` — один скомпилированный shader stage. `.lsp` — каталог нескольких
стадий и манифеста. `.ltp` — бинарный GPU-ready texture array; `.lt`
зарезервирован для будущего одиночного ресурса и сейчас не имеет runtime-
семантики. `.la` — один готовый к воспроизведению звук, `.lap` — каталог
таких звуков.

Имена проверяются до построения пути. Запрещены абсолютные пути, directory
separators, `..`, управляющие символы, зарезервированные Windows names и
конечные пробел/точка. Один pack не смешивает форматы разных категорий.
Каталог отклоняет неоднозначный набор, если два имени отличаются только
регистром ASCII: такой набор нельзя одинаково адресовать на Windows и Linux.

## Шейдеры

Шейдерпак — каталог `shaders/<name>.lsp`:

```text
pack.lm
chunk_vs.ls       chunk_ps.ls
panorama_vs.ls    panorama_ps.ls
ui_vs.ls          ui_ps.ls
```

`pack.lm` объявляет версию контейнера и renderer contract. Допустимо
поставить непустое подмножество стадий; отсутствующие стадии берутся из
встроенного набора. Точный контракт — в
[shaderpacks.md](shaderpacks.md).

## Текстуры

`.ltp` хранит один albedo `Texture2DArray`, а новая версия может дополнительно
содержать normal/AO array с тем же числом слоёв и mip-уровней. Все числа
little-endian, размеры bounded и согласуются с точным размером файла.
Точная раскладка — в [texturepacks.md](texturepacks.md).

## Звуки

Звукопак — каталог `sounds/<name>.lap` с файлами `.la` внутри. В отличие
от шейдерпака обязательного набора имён нет: имена звуков придумывает
приложение, а движок отдаёт звук по имени. Поэтому заменить любой звук —
значит положить в свой пак файл с тем же именем. Точная раскладка — в
[soundpacks.md](soundpacks.md).

## Активный выбор

`shaders/active.txt`, `textures/active.txt` и `sounds/active.txt` содержат UTF-8-имя одного
активного пака без пути. Пустой или отсутствующий файл означает встроенный
fallback. Одиночные `.ls`/`.lt`/`.la` через `active.txt` не выбираются.

Активация изменяет каталог, но не навязывает жизненный цикл renderer.
`RendererReloadTexturePackFrom` и `RendererReloadShaderPackFrom` выполняют
фактическую транзакционную замену из явного каталога. Звуки грузятся
поштучно через `AudioClipLoadFrom`, поэтому замены «на лету» у них нет:
приложение решает, когда перезагрузить свои клипы. Compatibility wrappers
используют каталог рядом с executable.
