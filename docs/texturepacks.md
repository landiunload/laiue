# Текстурпаки

Renderer использует GPU-ready `.ltp`: изображения и архивы во время загрузки
не декодируются. Активное UTF-8-имя хранится в `textures/active.txt`. Это
только имя файла: запрещены separators, управляющие символы, Windows device
names и конечные пробел/точка.

При первой подготовке без активного валидного pack используется нейтральный
встроенный 1×1 fallback. При hot reload повреждённый pack, I/O error или
ошибка создания GPU resource оставляют прежние texture arrays и descriptors
активными. `RendererReloadTexturePackFrom` читает явный каталог и выполняет
замену только после полного создания albedo и normal/AO replacement.

## Материалы и слои

LTP содержит от 1 до 64 слоёв одинакового квадратного power-of-two размера
от 1 до 4096 пикселей. Один слой соответствует одному непрозрачному
`BlockType`:

```text
BlockType 1 -> layer 0
BlockType 2 -> layer 1
...
```

Материал 0 зарезервирован для воздуха и обычно не попадает в меш. Если id
превышает число слоёв, renderer безопасно выбирает последний слой. Имена и
физические свойства материалов не записываются в LTP и принадлежат
приложению.

Все слои обязаны иметь одинаковые width, height, format и полную mip-цепочку.
Для version 2 после albedo-массива находится normal/AO-массив с точно той же
геометрией. Подготовка исходных изображений и сборка LTP выполняются внешним
offline-инструментом; runtime принимает только готовый бинарный payload.

## Формат LTP

Все числа little-endian. Header занимает 24 байта:

| Offset | Тип | Значение |
|---:|---|---|
| 0 | `u32` | magic `LTP1` (`0x3150544C`) |
| 4 | `u16` | version: 1 или 2 |
| 6 | `u16` | header size = 24 |
| 8, 10 | `u16` | width, height |
| 12 | `u16` | layer count: 1–64 |
| 14 | `u16` | полная цепочка mip до 1×1 |
| 16 | `u32` | format: 1 или 2 |
| 20 | `u32` | полный размер payload |

Внутри каждого слоя mip идут от исходного размера до 1×1, RGBA8 без
D3D12 row padding. Сначала последовательно записываются все albedo-слои.

- version 1 + format 1: только albedo;
- version 2 + format 2: после albedo расположен такой же по размеру блок
  normal/AO; RGB — касательная нормаль, A — ambient occlusion.

Loader требует допустимое число слоёв, точную mip-цепочку, согласованный
размер payload и отсутствие лишних байтов. Для version 1 renderer создаёт
плоскую normal/AO texture array с тем же числом слоёв.

Текстурпак меняет только отображение материала. Коллизии и остальные
прикладные свойства задаются отдельно от renderer.
