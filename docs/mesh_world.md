# Мир на мешах

`laiue.mesh_world` — бесконечный мир из размещённых моделей без вокселей и
чанков. Приложение ставит экземпляры моделей в любые координаты, а модуль
хранит их, отвечает на пространственные запросы и считает столкновения с
их коробками. Модели он не загружает, ничего не рисует и ничего не
генерирует: что где стоит, решает приложение или его поставщик ячеек.
Модулю не нужны другие модули движка, поэтому он работает и в headless-
профиле, и на сервере.

## Координаты

Позиция — целая ячейка `int64` по каждой оси плюс смещение `float` внутри
неё в метрах, ось Z вверх. Размер ячейки задаётся при создании мира
(`cellSize`, от 1 до 4096 м). На входе смещение может быть любым конечным:
мир сам переносит его в ячейку и хранит в `[0, cellSize)`.

Ячейки хранятся в пределах ±2⁶¹ по каждой оси. При ячейке 16 м это порядка
3,7·10¹⁹ м: дойти до края пешком не получится. Точность не зависит от
удалённости: каждый запрос считается в системе отсчёта своей ячейки, и во
`float` превращаются только разности ячеек внутри диапазона запроса.
`rebase` сдвигает начало на целое число ячеек, так что приложение,
хранящее собственное начало (например, `InfiniteCoord`), держит рабочие
координаты маленькими.

Ячейки — это пространственный индекс, а не чанки: у них нет содержимого
фиксированного формата, их не нужно создавать, а пустые ячейки не
занимают память. Экземпляр может быть больше ячейки и выступать за неё на
сколько угодно — запросы это учитывают.

## Формы и экземпляры

Форма регистрируется по номеру модели: габарит и до 64 ориентированных
коробок столкновений (`LaiueMeshShapeV1`). Удобно брать их из `.lo`:
`boundsMin/boundsMax` и коробки `COLL` пака моделей. Флаг
`LAIUE_MESH_SHAPE_COLLIDE_BOUNDS` делает коробкой сам габарит, когда своих
коробок нет. Повторная регистрация меняет форму уже размещённых
экземпляров.

Экземпляр — модель, позиция, поворот (кватернион), масштаб по осям,
флаги `VISIBLE` и `COLLIDABLE` и пользовательское `userData`. Хэндл несёт
поколение: после `remove` старый хэндл отвергается, даже если слот занял
новый экземпляр.

`cellRevision` меняется при любой правке ячейки: добавлении, удалении,
перемещении, смене флагов или формы. Значения берутся из общего счётчика
мира и не повторяются, поэтому ревизия однозначно называет состояние
содержимого ячейки и переживает `rebase`. Рендер-адаптер кэширует по ней
собранную геометрию ячейки.

## Запросы и столкновения

| Функция | Что делает |
|---|---|
| `queryCells` | занятые ячейки в радиусе, по порядку координат |
| `cellInstances` | экземпляры ячейки в порядке добавления |
| `sweepBox` | первый контакт движущегося AABB с коробками: время и нормаль |
| `moveBox` | движение со скольжением: до четырёх отрезков, признак опоры |
| `raycast` | луч до первой коробки; луч изнутри коробки её не видит |
| `overlapBoxes` | AABB коробок в области — вход `VoxelDynamicColliderQuery` физики |
| `blockSolid` | занят ли куб блока — вход `VoxelBlockPhysicsQuery` физики |

Пересечение ящика с повёрнутой коробкой проверяется по 15 разделяющим
осям, включая произведения рёбер. Ящик, уже вошедший в коробку,
выходит из неё свободно, а вглубь упирается сразу. `moveBox`
останавливается в миллиметре от поверхности, чтобы следующий шаг начинался
без касания. Опорой считается контакт с нормалью круче 45° вверх.

Чтение идёт параллельно, изменения сериализуются внутри мира.

## Поставщик ячеек

Чтобы мир наполнялся сам, приложение отдаёт `setProvider` функцию «что
лежит в этой ячейке». `stream(center, radius, budget)` вызывает её для
ячеек в радиусе (ближние первыми, не больше `budget` за вызов) и убирает
экземпляры поставщика из ячеек дальше радиуса плюс одна ячейка. Повторный
вызов из той же ячейки ничего не делает, а при переходе в соседнюю
проверяется только новый слой. Экземпляры, поставленные приложением
напрямую, поставщик не трогает. Смена или снятие поставщика убирает всё,
что он поставил.

```c
static uint32_t Ground(void *context, const LaiueMeshCellV1 *cell,
                       LaiueMeshInstanceDescV1 *out, uint32_t capacity,
                       uint32_t *outCount)
{
    *outCount = 0u;
    if (cell->z != 0)
        return 1u;              /* земля только на нулевом уровне */
    out[0] = GroundTile();      /* позиция относительно этой ячейки */
    *outCount = 1u;
    return 1u;
}
```

Так строится бесконечная земля, город или лес по любому правилу
приложения. Идти можно по любой оси: ячейки сверху и снизу
запрашиваются так же, как по сторонам. Радиус ограничен 64 ячейками.

## Производительность

Linux x64, GCC `-O3`, 200 000 экземпляров по одному на ячейку 16 м:

| Операция | Время |
|---|---:|
| `add` | 0,36 мкс |
| `moveBox` (ящик игрока, короткий шаг) | 0,23 мкс |
| `raycast` на 20 м | 0,16 мкс |
| `queryCells`, радиус 256 м | 110 мкс |
| `stream` с радиусом 256 м: первое наполнение | 3,5 мс |
| `stream`: переход в соседнюю ячейку | 0,34 мс |

## Проверки

`laiue.mesh_world.queries` проверяет нормализацию позиций, хэндлы с
поколением, ревизии, отсортированные и усечённые ответы, sweep по граням,
по ребру повёрнутой коробки и по разделяющей оси ребро×ребро, скольжение и
зазор, выход из пересечения, луч, блочный мост, выборку коллайдеров,
поздние формы, большие экземпляры из соседних ячеек, `rebase`, удаление
вперемешку 4096 ячеек и поставщика: наполнение, бюджет, ходьбу по X и Z,
`rebase`, отказ и повтор. Тот же сценарий столкновений повторяется в 2⁶⁰
ячейках от начала с тем же результатом.
