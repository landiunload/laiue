# Интеграция выборки halo — 10 сентября 2026

Проверен `world_halo_parallel_work.md`, включая его дополнение о записи
последовательных дельт отрезками. Сохранены обе оптимизации второй нейросети:
ограниченный обход отсортированных дельт соседей и последовательная запись
внутри колонны целиком попавшего в регион чанка. Новый перебор не меняет
shared-блокировку мира, provider callbacks, ревизии или публичный API.

## Исправлена отдельная старая ошибка

`RegionValid` разрешает регион с последним блоком `INT64_MAX`, однако
`minBlock + size - 1` сначала вычисляло `minBlock + size` и переполнялось.
Для такого случая теперь используется `minBlock + ((int64_t)size - 1)`.
Это существовало до halo-оптимизации и не является её регрессией.

Добавлен `TestRegionCoordinateLimits`: целые крайние чанки, частичные регионы
по всем трём осям, длины 1/2/63/64/65/66 у `INT64_MIN` и `INT64_MAX`.
Содержимое и классификация сверяются с отдельными запросами `WorldGetBlock`.
Невалидный регион, выходящий за `INT64_MAX`, должен оставить буфер неизменным.

До исправления UBSan с `halt_on_error=1` остановил тест на
`9223372036854775744 + 64 cannot be represented in type 'long int'`.
После исправления тот же тест и oracle мешера прошли. Логи:
`build/halo-endpoint-before.log`, `build/halo-endpoint-after.log`.

## Оставшиеся ограничения

Strict clang-tidy world/test не зелёный: 14 диагностик в `build/halo-tidy.log`.
Это явные приведения многократных указателей, расширение констант в тесте,
рекомендации Annex K для проверенных `memcpy`/`memset` и путь частично созданного
World в анализаторе. Последний не моделирует нулевое заполнение
`PlatformAllocate(..., true)`; реальный отказ allocator-а этим запуском не
проверялся. Глобальных отключений и объявления этих диагностик исправленными нет.

Семь отдельных `WorldFillRegion` вместо одного запроса пока не применены:
между ними поток записи может изменить мир. Проверка одного `WorldGetRevision`
не решает все случаи: счётчик насыщается, provider не имеет версии. Для такого
изменения сначала нужен явный контракт согласованного чтения.

Следующая независимая зона второй нейросети — `GreedyMeshPlanes`, его тест
и benchmark. Без изменения world/physics/API: уменьшение повторных проверок
материалов при слиянии длинных полос с прежним точным порядком квадов.
